# 👑 سامانه جامع مانیتورینگ قیمت رویال‌دیجی · ترب · دیجی‌کالا

این سامانه به‌صورت اختصاصی برای **پایش خودکار و مقایسه قیمت‌های سایت رویال‌دیجی (`royaldigi.ir`) با ترب و دیجی‌کالا**، شناسایی هوشمند مغایرت‌های قیمتی، نگهداری ترتیب دقیق انبار و استقرار ۱۰۰٪ رایگان روی **GitHub Pages** توسعه یافته است.

لیست محصولات مستقیماً از فایل‌های رسمی پوشه `sources/`:
- **`sources/links_torob_and_Digikala.xlsx`** (شامل ۱۶۶ محصول انبار، تفکیک نو و استوک، لینک‌های ترب و دیجی‌کالا)
- **`sources/royaldigi-products-urls.csv`** (آدرس‌های مستقیم کالاها روی سایت رویال‌دیجی)

## ✨ ویژگی‌ها و نوآوری‌های کلیدی سامانه

1. **۳ ستون مقایسه قیمت همزمان:**
   - **قیمت رویال‌دیجی (سایت خودمان):** استخراج مستقیم بر اساس `Woo ID` و اسلاگ کالا از داده‌های ساختاریافته Schema.org JSON-LD.
   - **قیمت ترب (لینک اصلی):** استخراج از لینک اصلی محصول در ترب (`لینک ترب` و نه استوک).
   - **قیمت دیجی‌کالا:** استخراج لحظه‌ای از API دیجی‌کالا به همراه نام فروشنده.
2. **هایلایت قرمز برای مغایرت قیمت با میانگین بازار:**
   - ستون و سلول قیمت رویال‌دیجی در صورتی که با **میانگین بازار (ترب و دیجی‌کالا)** تفاوت داشته باشد، به‌صورت کاملاً مشخص به **رنگ قرمز با نشانگر ⚠️** درمی‌آید تا در یک نگاه کالاهای نیازمند اصلاح قیمت مشخص شوند.
3. **حفظ دقیق ترتیب کالاها مطابق با فایل:**
   - ترتیب نمایش کالاها در سایت و جدول به صورت پیش‌فرض **دقیقاً بر اساس ترتیب ردیف‌های فایل اکسل** (از ۱ تا ۱۶۶) چیده شده است.
4. **رنگ‌بندی مجزا برای کالاهای نو و استوک:**
   - **کالای نو (New):** برچسب سبز درخشان 🟢
   - **کالای استوک (Stock):** برچسب بنفش/کهربایی 🟣
   - فیلترهای یک‌کلیکی برای تفکیک نو و استوک در بالای جدول.
5. **تکنیک ضد بن و تاخیر تصادفی انسانی (Random Jitter):**
   - برای جلوگیری از مسدود شدن توسط فایروال‌ها، درخواست‌ها به جای شلیک ناگهانی، به صورت متوالی و با تاخیر تصادفی انسانی **۲.۵ تا ۴.۵ ثانیه** ارسال می‌شوند.
6. **زمان‌بندی هوشمند روزانه ساعت ۱۰:۰۰ صبح:**
   - در گیت‌هاب اکشنز ساعت اجرا روی **۱۰:۰۰ صبح هر روز به وقت تهران (06:30 UTC)** تنظیم شده تا خطر مسدودیت به صفر برسد و سهمیه مصرف نشود.
7. **دکمه شروع آپدیت («🔄 شروع آپدیت قیمت‌ها»):**
   - در هدر سایت دکمه اختصاصی تعبیه شده که با کلیک روی آن مودال راهنما و دکمه اجرای دستی با یک کلیک در گیت‌هاب اکشنز باز می‌شود.
8. **گزینه به‌روزرسانی فقط مغایرت‌ها:**
   - امکان اجرای اسکریپت با پرچم `--only-discrepancies` برای اسکرپینگ اختصاصی کالاهایی که قیمت رویال با بازار اختلاف دارد.
9. **داشبورد تک‌فایلی مستقل ([dashboard.html](file:///d:/price-monitor/price-monitor/dashboard.html)):**
   - فایلی کامل و بدون نیاز به اینستال هیچ برنامه‌ای که با دابل‌کلیک در ویندوز باز می‌شود و داده‌های کامل ۱۶۶ محصول را نمایش می‌دهد.
10. **خروجی اکسل به‌روزرسانی شده با استایل ([گزارش_انبار_قیمت_به_روز.xlsx](file:///d:/price-monitor/price-monitor/گزارش_انبار_قیمت_به_روز.xlsx)):**
    - همراه با سلول‌های قرمز رنگ برای مغایرت‌ها و سبز برای قیمت‌های منطبق.

## 🚀 نحوه استقرار روی GitHub Pages

### ۱. پوش کردن به مخزن گیت‌هاب
با نرم‌افزار **GitHub Desktop** یا **VS Code**، پوشه پروژه را باز کرده و تغییرات را **Commit & Push** کنید:
```bash
git add .
git commit -m "feat: RoyalDigi price monitor with Torob & Digikala, discrepancy highlights and daily 10AM schedule"
git push origin main
```

### ۲. تنظیمات اولیه مخزن در گیت‌هاب (فقط یک‌بار)
1. در صفحه مخزن خود در GitHub به تب **Settings** بروید.
2. از منوی سمت چپ به **Actions** > **General** رفته و در بخش **Workflow permissions** گزینه **Read and write permissions** را انتخاب کنید و **Save** را بزنید.
3. از منوی سمت چپ وارد بخش **Pages** شوید و در قسمت **Source** گزینه **GitHub Actions** را انتخاب کنید.

### ۳. اجرای دستی یا زمان‌بندی خودکار
- سیستم هر روز رأس ساعت **۱۰:۰۰ صبح (تهران)** به‌طور خودکار اجرا می‌شود.
- در هر لحظه نیز می‌توانید از تب **Actions** گیت‌هاب، ورک‌فلو **Monitor Prices & Deploy to GitHub Pages** را انتخاب کرده و دکمه **Run workflow** را بزنید تا سایت ظرف ۱ الی ۲ دقیقه آپدیت شود.

## 💻 دستورات اجرای محلی اسکریپت پایتون

```bash
# به‌روزرسانی تمام ۱۶۶ محصول با تاخیر انسانی ضد بن
python scripts/update_prices.py

# به‌روزرسانی فقط محصولاتی که قیمت رویال با بازار مغایرت دارد
python scripts/update_prices.py --only-discrepancies

# تست اولیه با تعداد محدود (مثلاً ۵ کالا)
python scripts/update_prices.py --limit 5
```
