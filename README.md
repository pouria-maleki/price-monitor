# 📊 سیستم هوشمند مانیتورینگ قیمت محصولات (Price Monitor)

این سیستم به‌صورت اختصاصی برای **پایش و مقایسه خودکار قیمت محصولات انبار** با سایت‌های **دیجی‌کالا** و **ترب**، ذخیره تغییرات، تولید فایل اکسل به‌روز و میزبانی رایگان روی **GitHub Pages** توسعه یافته است.

لیست محصولات از فایل اکسل انبار (`گزارش انبارمون - لینک و قیمت.xlsx`) شامل **۳۲ محصول نو** و **۶۸ محصول استوک** (مجموعاً ۱۰۰ محصول) خوانده می‌شود.

---

## 🚀 ویژگی‌های کلیدی سیستم

1. **هاست رایگان روی گیت‌هاب (GitHub Pages):**
   - بدون نیاز به اجاره سرور، دیتابیس یا VPS. فرانت‌اند به‌صورت کاملاً رایگان روی گیت‌هاب میزبانی می‌شود.
2. **بروزرسانی خودکار با GitHub Actions:**
   - هر ۶ ساعت یک‌بار (یا با کلیک یک دکمه در گیت‌هاب)، سرورهای گیت‌هاب اسکریپت را اجرا کرده، قیمت‌های جدید دیجی‌کالا و ترب را استخراج می‌کنند و سایت را خودکار آپدیت می‌نمایند.
3. **مقایسه قیمت پایه اکسل با قیمت روز:**
   - محاسبه دقیق درصد افزایش (🔺 قرمز) یا کاهش (🔻 سبز) قیمت نسبت به قیمت اولیه‌ای که در اکسل انبار داشتید.
4. **خروجی فایل اکسل جدید و به‌روزرسانی‌شده:**
   - تولید خودکار فایل `گزارش_انبار_قیمت_به_روز.xlsx` با تفکیک شیت‌های «محصولات نو» و «محصولات استوک»، درج قیمت جدید دیجی‌کالا، فروشنده، وضعیت موجودی و درصد تغییرات.
   - امکان دانلود مستقیم این فایل از داخل داشبورد سایت.
5. **رفع خطاهای اسکریپرها:**
   - **دیجی‌کالا:** مهاجرت از اندپوینت قدیمی `v1` (که خطای 404 می‌داد) به API نسخه `v2` دیجی‌کالا، استخراج قیمت به تومان، فروشندگان مختلف و وضعیت موجودی واقعی.
   - **ترب:** مدیریت هوشمند سامانه ضدربات (کد ۴۹۰) و پشتیبانی از کوکی تاییدیه `trb_clearance`.
6. **داشبورد فارسی و ریسپانسیو:**
   - کارت‌های آماری (تعداد کل، نو، استوک، تعداد افزایش قیمت‌ها، کاهش قیمت‌ها و ناموجودها).
   - جستجوی آنی بر اساس نام محصول یا کد انبار (مانند `C80`، `AX23`، `L02`).
   - فیلتر بر اساس دسته‌بندی و وضعیت تغییر قیمت، و مرتب‌سازی پیشرفته.

## 🌐 نحوه میزبانی رایگان روی گیت‌هاب (GitHub Pages)

برای اینکه سایت شما روی آدرس `https://<username>.github.io/<repo-name>/` بالا بیاید:

### ۱. ساخت ریپازیتوری در گیت‌هاب و Push کردن کدها

در ترمینال سیستم خود دستورات زیر را وارد کنید:

```bash
git init
git add .
git commit -m "feat: Price monitor with GitHub Pages & Actions"

# یک ریپازیتوری جدید (Public یا Private) در سایت github.com بسازید، سپس:
git branch -M main
git remote add origin https://github.com/<نام-کاربری-شما>/<نام-ریپازیتوری>.git
git push -u origin main
```

### ۲. فعال‌سازی GitHub Pages در تنظیمات گیت‌هاب

1. در صفحه ریپازیتوری در سایت GitHub به تب **Settings** بروید.
2. از منوی سمت چپ روی گزینه **Pages** کلیک کنید.
3. در بخش **Build and deployment**، گزینه **Source** را از حالت Deploy from a branch به **GitHub Actions** تغییر دهید.
4. کار تمام است! ورک‌فلو موجود در `.github/workflows/monitor_and_deploy.yml` به صورت خودکار اجرا شده و سایت شما را منتشر می‌کند.

### ۳. تنظیم نوتیفیکیشن تلگرام (اختیاری)

اگر می‌خواهید هنگام تغییر قیمت‌ها در تلگرام پیام دریافت کنید:
1. در ریپازیتوری گیت‌هاب به **Settings** > **Secrets and variables** > **Actions** بروید.
2. با کلیک روی **New repository secret** متغیرهای زیر را بسازید:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام (از @BotFather)
   - `TELEGRAM_CHAT_ID`: شناسه عددی چت یا کانال شما (از @userinfobot)
   - `TOROB_CLEARANCE_COOKIE`: (اختیاری) در صورت داشتن کوکی عبور از تست ربات ترب

## 💻 نحوه استفاده روی سیستم محلی (ویندوز)

### ۱. استخراج و بروزرسانی قیمت‌ها با پایتون

هر زمان که بخواهید قیمت‌های کل محصولات را به صورت دستی بروزرسانی کنید:

```bash
# بروزرسانی تمامی ۱۰۰ محصول انبار
python scripts/update_prices.py

# یا بروزرسانی سریع فقط چند محصول برای تست
python scripts/update_prices.py --limit 5
```

این دستور قیمت‌های روز را استخراج کرده و موارد زیر را تولید می‌کند:
- فایل اکسل جدید: `گزارش_انبار_قیمت_به_روز.xlsx`
- فایل داده‌های فرانت‌اند: `data/products_data.json`

### ۲. مشاهده داشبورد به صورت آفلاین / محلی

کافیست فایل `dashboard.html` موجود در ریشه پروژه را با دابل کلیک در مرورگر خود (Chrome / Edge / Firefox) باز کنید. داشبورد کامل به همراه جستجو، فیلترها، آمارها و لینک‌ها بدون نیاز به اینترنت یا سرور اجرا خواهد شد.

همچنین می‌توانید با وب‌سرور داخلی پایتون آن را اجرا کنید:
```bash
python -m http.server 8000
```
سپس در مرورگر آدرس `http://localhost:8000/dashboard.html` را باز کنید.

```
│   ├── src/
│   │   ├── api.js                   # کلاینت همه‌منظوره (سازگار با GitHub Pages و API)
│   │   ├── components/              # جداول، کارت‌های آماری، نمودار و جزئیات
│   │   └── App.jsx
│   └── vite.config.js               # تنظیم base: './' برای گیت‌هاب پیجز
├── scraper/                         # موتورهای استخراج اطلاعات
│   ├── base.py                      # ابزارهای تبدیل قیمت و اتصال شبکه
│   ├── digikala.py                  # استخراج از API v2 دیجی‌کالا و فروشندگان

│   └── notifier.py                  # ارسال هشدار به تلگرام
├── scripts/
│   └── update_prices.py             # اسکریپت اصلی خواندن اکسل، استخراج و تولید خروجی
├── dashboard.html                   # داشبورد مستقل و بدون وابستگی برای اجرای سریع لوکال
├── گزارش انبارمون - لینک و قیمت.xlsx # فایل اکسل ورودی انبار شما
├── گزارش_انبار_قیمت_به_روز.xlsx       # فایل اکسل خروجی تولیدشده با آخرین قیمت‌های روز
├── requirements.txt                 # پکیج‌های پایتون (requests, openpyxl)
└── README.md
```
